# Запуск через бесплатный Gemini API вместо OpenAI Billing

В проекте уже используется библиотека `openai` как HTTP-клиент. Это не означает, что обязательно нужен платный OpenAI API: можно направить этот клиент на OpenAI-compatible endpoint Google Gemini.

## 1. Получить API key

1. Откройте https://aistudio.google.com/api-keys.
2. Войдите в Google account.
3. Создайте API key для Google AI Studio. Выберите/создайте проект, который предлагает интерфейс.
4. Не публикуйте ключ и никому его не отправляйте.

Google указывает для Free tier бесплатные input/output tokens у некоторых моделей, включая Gemini Flash. На бесплатном уровне действуют лимиты по модели и аккаунту; их текущие значения нужно смотреть в AI Studio. Google также предупреждает, что содержимое Free tier может использоваться для улучшения продуктов. Не отправляйте через бесплатный ключ секреты, пароли, приватные данные и персональную информацию.

Официальные страницы:
- OpenAI compatibility: https://ai.google.dev/gemini-api/docs/openai
- Pricing: https://ai.google.dev/gemini-api/docs/pricing
- Rate limits: https://ai.google.dev/gemini-api/docs/rate-limits

## 2. Настроить `.env`

В корне проекта откройте `.env`. Заполните следующие строки (замените placeholder реальным Gemini API key):

```dotenv
GEMINI_API_KEY=PASTE_YOUR_GEMINI_API_KEY_HERE
GEMINI_MODEL=gemini-3.1-flash-lite
# Необязательно: если оставить пустым, приложение подставит официальный endpoint само.
GEMINI_BASE_URL=
```

Другие настройки `TELEGRAM_*`, `MANAGER_USERNAME` и `TEST_MANAGER_USERNAME` остаются такими же. При наличии `GEMINI_API_KEY` программа автоматически выбирает Gemini endpoint и модель. Старые `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_BASE_URL` продолжают поддерживаться.

Если именно эта модель недоступна в вашем AI Studio аккаунте, выберите доступную Flash-модель в AI Studio и укажите её точный model ID в `GEMINI_MODEL`. Не угадывайте идентификатор.

## 3. Сначала проверить API и tool calling без Telegram

```powershell
python check_provider.py
```

Скрипт отправляет два коротких тестовых запроса: просит модель вызвать безопасную тестовую функцию и затем проверяет продолжение после результата функции. Telegram не запускается, сообщения менеджеру не отправляются, бронь не создаётся.

Ожидаемый результат:

```text
PASS: gemini-3.1-flash-lite completed a multi-turn tool-call round-trip.
Telegram was not contacted and no booking message was sent.
```

Если появляется `429`, это может быть ограничение бесплатной квоты/rate limit; дождитесь сброса или проверьте лимиты в AI Studio. Ошибки `400`/`404` обычно означают несовместимый запрос, endpoint или model ID. Ошибка `401` означает неверный/отозванный ключ.

## 4. Запустить агента в режиме dry-run с настоящей моделью

Пока 17:00 по Лондону впереди:

```powershell
python run.py --dry-run
```

После 17:00 по Лондону для офлайн-проверки разрешена подмена часов:

```powershell
python run.py --dry-run --simulate-time 12:00
```

Вводить ответы менеджера нужно только в строку `manager>` внутри работающей программы. Каждую новую беседу запускайте отдельной командой `python run.py ...`. Если снова видите приглашение Windows вида `(.venv) C:\...>`, программа уже завершилась; текст ответа менеджера в этот момент будет воспринят Windows как команда.

## 5. Только потом Telegram

Сначала используйте отдельный тестовый аккаунт и заполненный `TEST_MANAGER_USERNAME`:

```powershell
python run.py --test
```

Не запускайте настоящий сценарий с `@vlad_dev_7`, пока не проверены: успешный `check_provider.py`, работа агента с настоящей моделью в `--dry-run` и отправка/получение сообщений через тестовый Telegram-аккаунт.

Реальный менеджер — только отдельное осознанное решение оператора. Запуск без `--test` отправляет первое сообщение реальному менеджеру; одной офлайн-проверки или успешного API preflight для этого недостаточно.

## 6. Важные замечания

- Gemini key не является OpenAI key; он передаётся через `GEMINI_API_KEY`.
- Вызов `check_provider.py` не доказывает качество диалога и не заменяет сценарное тестирование.
- Проект не может гарантировать доступность бесплатной квоты: Google меняет лимиты, а квоты могут зависеть от проекта/региона/состояния аккаунта.
- `--simulate-time` запрещён при обращении к реальному менеджеру. Используйте его только с `--dry-run` или `--test`.
- Не отправляйте `.env`, Telegram session-файлы и содержимое с API key в чат или GitHub.
