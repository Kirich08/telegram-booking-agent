# Пошаговая установка (для новичка)

Этот файл для вас. README.md — для GitHub и проверяющих.

## Шаг 1. Установите Python 3.10+

Проверьте версию в терминале:

```bash
python --version      # Windows; на macOS/Linux может понадобиться python3 --version
```

Если версия ниже 3.10, установите новую с python.org.

## Шаг 2. Установите ffmpeg (только для голоса)

Для текстовой версии ffmpeg не нужен. Для голоса см. `VOICE.md`.

## Шаг 3. Откройте папку проекта и создайте виртуальное окружение

```bash
cd booking_agent
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
```

В начале строки терминала появится `(.venv)`. Это значит, что окружение активно.

## Шаг 4. Установите зависимости

```bash
pip install -r requirements.txt
```

## Шаг 5. Проверьте, что всё запускается без ключей

```bash
python run.py --help
python run.py --mock --dry-run --simulate-time 12:00
```

Во втором случае агент напишет первое сообщение, и вы сможете ответить за менеджера
текстом в консоли. Введите, например: `Yes, we have a table. What is the name?`.
Чтобы выйти, напишите `/quit`.

Если всё работает, файл `decisions.log` появится в папке проекта. Откройте его:
это лог решений.

## Шаг 6. Создайте отдельный Telegram-аккаунт

Не используйте основной аккаунт. Нужен второй номер телефона и вход в Telegram на нём.

## Шаг 7. Получите api_id и api_hash

1. Откройте https://my.telegram.org и войдите номером **тестового** аккаунта.
2. Откройте «API development tools».
3. Заполните форму (название и короткое название любые).
4. Скопируйте `App api_id` и `App api_hash`.

## Шаг 8. Получите ключ модели (OpenAI или бесплатный Gemini)

**Если не можете пополнить OpenAI, используйте Gemini:** откройте https://aistudio.google.com/api-keys и создайте API key. На бесплатном уровне доступны отдельные модели с бесплатными input/output tokens и дневными/минутными ограничениями. В `.env` укажите `GEMINI_API_KEY`; модель и endpoint по умолчанию уже настроены в `.env.example`. См. подробную инструкцию `GEMINI_FREE_SETUP.md`.

Либо используйте OpenAI API key и положительный API balance. Для него заполните `OPENAI_API_KEY`. Эти два варианта не требуют менять код агента.

## Шаг 9. Создайте `.env`

Windows:
```bash
copy .env.example .env
```
macOS / Linux:
```bash
cp .env.example .env
```

Откройте `.env` в блокноте и заполните (для бесплатного Gemini):

```
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
TELEGRAM_PHONE=+380...           # номер тестового аккаунта
GEMINI_API_KEY=ваш_ключ_Google_AI_Studio
MANAGER_USERNAME=@vlad_dev_7
TEST_MANAGER_USERNAME=@ваш_второй_аккаунт
```

`.env` нельзя отправлять в чат, на GitHub и никуда. Он уже в `.gitignore`.

## Шаг 10. Первый вход в Telegram

```bash
python run.py --test
```

Telegram пришлёт код в приложение на тестовом аккаунте. Введите его в консоли.
Если включена двухфакторная защита, попросят пароль; он не отображается при вводе.
Дальше сессия сохраняется в `booking_agent.session`, и код больше не нужен.

Агент напишет вашему тестовому аккаунту. Ответьте с основного телефона
(или с третьего аккаунта) как менеджер.

## Шаг 11. Реальный менеджер

Когда тест прошёл, запускайте без `--test`:

```bash
python run.py
```

Агент напишет `@vlad_dev_7`. Не запускайте это много раз подряд: один запуск — одна попытка.

## Частые ошибки

- `python` не найден → попробуйте `python3` или переустановите Python с галочкой «Add to PATH».
- `Configuration error` → не создан `.env` или не заполнено поле, которое перечислено в ошибке.
- Ошибка при `pip install` → обновите pip: `python -m pip install --upgrade pip`.
- Код из Telegram не приходит → подождите минуту, проверьте уведомления, при повторе запустите программу заново.

## Полный сброс

```bash
python run.py --logout     # выйти из Telegram и удалить сессию
```
