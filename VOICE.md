# Голос (задача со звёздочкой)

## Что делает агент в голосовом режиме

- **Исходящие:** каждое сообщение агента уходит как **голосовое** (британский голос
  `en-GB-RyanNeural`), а тот же текст стоит в подписи. Подпись нужна, чтобы менеджер
  мог прочитать, если не хочет слушать, и чтобы переписка читалась на скриншоте.
- **Входящие:** если менеджер присылает голосовое, оно скачивается, распознаётся
  (`faster-whisper`, модель `base`, локально) и текст передаётся агенту. В логе
  такая реплика помечена `[voice message, transcribed]`.
- **Если что-то не сработало** (нет ffmpeg, нет пакета, нет интернета, ошибка синтеза),
  агент отправляет обычный текст и пишет предупреждение в консоль. Бронирование из-за
  голоса не ломается.
- OpenAI для голоса **не используется**, поэтому у ключа OpenAI права на аудио не нужны.

## Установка

1. ffmpeg:
   - Windows: `winget install ffmpeg` (потом откройте новый терминал)
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

   Проверка: `ffmpeg -version`.
2. Пакеты (в активном `.venv`):
   ```bash
   pip install -r requirements-voice.txt
   ```
   В файле есть `requests`: без него `faster-whisper==1.0.3` может не запуститься.
3. В `.env`: `ENABLE_VOICE=true`.
4. Запуск с флагом: `python run.py --voice` (или `--test --voice`).

Нужны **оба** условия: `ENABLE_VOICE=true` и флаг `--voice`. Если чего-то не хватает,
программа напишет, что именно, и продолжит текстом.

## Первый запуск

При первом распознавании `faster-whisper` скачивает модель `base` (порядка сотен МБ)
с интернета. Это один раз; первая расшифровка будет медленной.

## Как проверить вручную

1. `python run.py --dry-run --voice`: агент сгенерирует голосовое. В dry-run оно не
   отправляется, консоль покажет путь к файлу. Проверка: синтез и конвертация работают.
2. `python run.py --test --voice`: на тестовом аккаунте придёт голосовое с подписью.
   Отправьте в ответ голосовое: в консоли должна появиться расшифровка.

## Что проверено и что нет

Проверено автоматически (`python -m unittest test_voice -v`): конвертация в OGG Opus
через настоящий ffmpeg, удаление временных файлов, все пути отката на текст.

**Не проверено** (нужен интернет и ваши ключи): настоящий синтез `edge-tts`, настоящее
распознавание `faster-whisper`, и как Telegram показывает подпись под голосовым.
`edge-tts` — это неофициальный бесплатный сервис, он может перестать работать; тогда
агент продолжит текстом. Укажите это в нотах.
